# GSP529 - Develop AI-Powered Prototypes in Google AI Studio: Challenge Lab

This lab has no Cloud Shell. You build one app in Google AI Studio by pasting prompts, one per task. The prompts are in copy blocks. After every task: wait for the build to finish, try the app once, SAVE, then click the check.

## Known lab traps/bugs (read first)

1. Build in the right place. The app must be made under BUILD > New app in the left menu. A prompt typed into Playground gives you a chat answer with code in it, which is not an app, and the Task 1 check fails.
2. Save after every task. The checker reads the saved app, not what is on your screen. An unsaved change scores 0 even when the app works.
3. Saving needs Drive access. Do the lab's Drive step once at the start (Add files menu > Drive > pick the student account > allow). Without it the save has nowhere to go.
4. Use the lab's exact words for buttons and labels (Generate, Regenerate, Generate Backstory, Health, Mana, Strength, Save to Deck, My Deck). The prompts below already spell them out so the checker can find them in the app.
5. Keep working in the same app for all six tasks. Starting a new app for a later task loses the earlier features.
6. AI results vary. If a build breaks the app or leaves out something the task asks for, paste the same prompt again or use the repair prompt at the end of this file, then save again.
7. A red message "Failed to generate API key, You do not have permission to generate API keys" can pop up while the app builds. The student account is not allowed to make keys. Close the message and let the build finish, the app is still created and can be saved.
8. In Task 2 the assistant may refuse to build portraits and ask you to "select a paid API key". Do not link a key. Use the Task 2 prompt in this file, which tells it to build the feature without one.
9. Wrong account: open AI Studio in the Incognito window with the lab's student account. The checker lags too, wait 30-60 seconds and click again if a check fails.

## Before Task 1

1. Open Google AI Studio in the Incognito window and sign in with the lab's student account.
2. In the left menu, under BUILD, click New app. This is the app builder. Do NOT type the prompts into Playground (under EXPLORE): Playground is a plain chat, it only prints code and creates no app, so nothing can be saved or scored.
3. Do the lab's Drive step in the app builder: in the Add files menu click Drive, pick the student account and grant the permissions.
4. A window titled "Select or upload a file" opens, showing your Drive. That window means access is granted. Do not pick anything: close it with the X in its top right corner.

## Task 1. Generate the core application

Paste this into the prompt box of the New app page (BUILD > New app) and start the build:

```text
Build a web app called Fantasy Character Generator. It has one button labeled "Generate Character". When the button is clicked, the app generates and displays a random fantasy character with a unique Name and a Class, for example Mage, Rogue or Warrior. Show the Name and the Class clearly on the page.
```

When it is done you should see a live preview of the app next to a code assistant chat, not just a block of code. Click the button in the preview: a name and a class should appear. Save the app. It should now be listed under BUILD > My apps.

Check my progress: Generate the core application from a prompt

## Task 2. Add the character portraits feature

Paste into the Code Assistant chat of the same app:

```text
Add a character portrait feature now, and do not stop to ask me for a paid API key. Add a button labeled "Generate" that creates a cartoon/video game style portrait image of the character currently displayed, using its Name and Class, and shows the image on the page. Add a second button labeled "Regenerate" that creates a new portrait for the same character. Use only what is available to this app without a paid key: have the default Gemini model write the portrait as an SVG image, and if that call fails, draw a simple cartoon portrait in code so an image always appears. Keep everything that already works.
```

If a panel titled "Upgrade to a paid API key" appears, close it with its X. Do not link a key: the student account has none, and the prompt above is written so the feature is built without one.

Try it: generate a character, then Generate and Regenerate a portrait. Save the app.

Check my progress: Add the character portraits feature to the application

## Task 3. Refine the UI

```text
Restyle the whole app to look and feel like an ancient alchemist's workbench. Use a dark, textured background, and a stylized, fantasy-style font for the character's name. Keep all existing features and button labels unchanged.
```

Look at the preview: dark textured background, fantasy lettering on the name. Save the app.

Check my progress: Improve the user interface with required specifics

## Task 4. Add the character backstory feature

```text
Add a button labeled "Generate Backstory". When clicked, it generates a unique origin story of one to two sentences for the character currently on screen, based on its Name and Class, and displays it under the character. Keep all existing features and button labels unchanged.
```

Try it: a short backstory should appear for the current character. Save the app.

Check my progress: Add the character backstory feature to the application

## Task 5. Player card, stats and Save to Deck

```text
Reformat the entire UI into a bordered player card that holds the portrait, Name, Class and backstory. Add new randomly generated stats to the card, labeled exactly Health, Mana and Strength, created each time a character is generated. Add a button labeled "Save to Deck" that saves the current character into a list titled "My Deck" shown within the app. Keep all existing features and button labels unchanged.
```

Try it: the card has a border and three stats, and Save to Deck adds the character under My Deck. Save the app.

Check my progress: Add player card, stats, and 'save to deck' functionality to the application

## Task 6. Save your prototype

1. Rename the app so its name is exactly:

```text
Fantasy Character Generator
```

2. Save the app once more.
3. Download the source code as a ZIP file (the download option of the app).

This task has no check button of its own in the lab text. The lab reads your saved app for the final score.

## Repair prompt (only if a build broke something)

```text
The last change broke the app or left something out. Fix all errors and make sure these all exist and work, with these exact labels: a Generate Character button showing Name and Class, Generate and Regenerate portrait buttons, a Generate Backstory button, a bordered player card with Health, Mana and Strength stats, and a Save to Deck button that adds the character to a My Deck list.
```
